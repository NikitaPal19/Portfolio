Projects

Things I've built.

A few projects worth a closer look.

resumeiq/

ResumeIQ

Full-stack CV analysis app, powered by LLMs.

Problem Job seekers bounce between five different tools — one for ATS scoring, another for rewriting bullets, another for tailoring a resume to a specific JD — and get inconsistent, generic advice from each.
Approach
  • Built a LangChain pipeline chaining ATS scoring, a CV health check, and a bullet rewriter into one flow
  • Used structured Pydantic outputs so every LLM response is validated, not just free text
  • Added a career-coach chat with memory and multi-JD comparison for tailoring one resume to several roles
  • Shipped an AI-updated CV export straight to PDF via fpdf2, so the output is usable immediately
Result
6 tools consolidated into 1 workflow

Replaces a five-tab manual process with a single guided pass — from raw resume to ATS-ready, JD-tailored output.
iu-academic-ai-bot/

IU Academic AI Bot

AI-powered academic assistant for Indira University students.

ProblemStudents need a reliable way to get answers about the M.Sc. Artificial Intelligence & Data Science program, including syllabus, timetable, admissions, careers, and university information.
ApproachBuilt a Streamlit chatbot using RAG with ChromaDB for syllabus and timetable retrieval, a curated university knowledge base, and Groq model routing with real-time web search as a fallback. Added guardrails and graceful error handling to avoid hallucinated answers.
Result
RAG + real-time web search

Provides semantic retrieval from local university data and routes questions requiring live information to web search, while clearly stating when information is unavailable.
